# office-arr

A suite of small desktop apps, built by a team of persistent Claude Code agents.

- `src/`: the apps. First up: `time-arr`, an Avalonia timer.
- `agents/`: the agent team. `STANDING.md` holds the rules every agent follows; each
  agent has its own folder with a `CLAUDE.md`.
- `office-arr.code-workspace`: VS Code / VSCodium workspace for the whole repo.

Start the worker agents with `agents/start.sh`.
